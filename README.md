Setup:
  Requirements:
    1. Python 3
    2. Jupyter Notebook or VS Code
    3. The insurance_claims.csv dataset from Kaggle

Installation:
  1. Download or clone this repository.
  2. Download the insurance_claims.csv dataset and place it in the same folder as auto_insurance.ipynb.
  3. Install the required Python packages:
      pip install -r requirements.txt

Running the Analysis:
Open auto_insurance.ipynb in Jupyter Notebook or VS Code and run the cells from top to bottom.
The notebook will load the insurance claims dataset, create the SQLite database used for the analysis, perform the SQL queries, and generate the statistical analyses and visualizations.
